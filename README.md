Overview
A 2D top-down bartending game built in Godot 4.5. The player works behind a bar counter, serving customers drinks across multiple shifts. Customers walk in, order drinks through dialogue, and the player crafts drinks using interactive ingredients, machines, and tools. Drinks are scored based on accuracy to the recipe.
